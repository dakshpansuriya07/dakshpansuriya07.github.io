01

The Receipt

16:9 · YouTube · 3:38 film, first 1:15 shown

Why AI's compute bill can't keep multiplying. A till receipt for one training run starts printing and never stops; each line item unfolds into a small illustrated scene.

My part

Research and script, every number sourced. Illustration drawn as SVG in code, animation keyed to the voice, sound and mix.

Craft

One persistent object and a continuous camera instead of cuts. Totals roll like slot-machine digits.

Tools

HyperFrames (HTML, CSS, GSAP), SVG, synthetic narration (Kokoro), ffmpeg.

Never Pay for AI

9:16 · Shorts · 0:38 excerpt

A short on home AI supercomputers. This excerpt explains memory bandwidth with one picture: the model is a library, and the writer has to read every book through one door before each word.

My part

Tools

03

Salt Hollow

Rough cut16:9 · 0:39 · 27 shots

A cartoon show open for an original foggy sea town, cut shot-for-shot to the timing of a classic 2012 TV-cartoon open. Original town, cast, logo and score.

My part

Character kit as layered, rig-ready SVG; painted backgrounds built from SVG filters; animation, edit to a bar-timed score, 25 sound effects.

Craft

Cuts snap to the score's downbeats, within a few frames of the reference timing.

Tools

HyperFrames (GSAP), SVG, Python for the cut grid; score made with ElevenLabs Music.
